# Third-party software

- **mp-tikz-wasm 0.4.0**, LGPL-3.0-or-later glue; **LuaTeX 1.21.0 WASM**, GPL-2.0-or-later. Source and reproducible build: https://github.com/jmckalex/mp-tikz-wasm/tree/v0.4.0 ; underlying TeX Live source and patches are pinned in that repository's build scripts. Download: https://github.com/jmckalex/mp-tikz-wasm/releases/tag/v0.4.0 . `scripts/setup.mjs` verifies the release archive's SHA-256. Licence texts and component notice are installed under `vendor/engine/`. Only LuaTeX, the VFS helper and selected free TeX/font bundles are shipped; Classico and Ghostscript bundles are excluded.
- **TeX packages and fonts**, their respective LPPL, Knuth, AMS, GUST and other licenses, as recorded in the engine's `NOTICE.md` and package source headers. Derived Type 1 glyph-outline JSON preserves the font's license. The source `.pfb` files are retained in the deployed bundles; `scripts/type1-outlines.py` is the reproducible conversion script.
- **ctablestack 1.0**, LPPL 1.3c, catcode-table support used by luatexbase. Setup downloads the upstream TDS archive, verifies its SHA-256 and installs the unmodified package as `vendor/ctablestack.sty`. Source distribution: https://ctan.org/pkg/ctablestack ; archive containing the package and its source: https://mirrors.mit.edu/CTAN/install/macros/luatex/generic/ctablestack.tds.zip .
- **CTeX 2.5.10**, LPPL 1.3c; **LuaTeX-ja 20260130.1**, BSD; **Chinese JFM 1.1.1**, MIT; **zhnumber 3.0**, LPPL 1.3c; **lua-uni-algos 0.5**, LPPL 1.3; **Fandol 0.3**, GPL with the font exception. Chinese runtime packages and fonts come from the immutable [TeX Live 2025 final archive](https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2025/tlnet-final/archive/), with SHA-256 pins in `scripts/setup.mjs`. This version of CTeX matches the bundled LaTeX 2025 kernel. The archive also provides corresponding `.source.tar.xz` packages where applicable. Package headers, documentation licence/readme files and TeX Live metadata are preserved in `vendor/engine/bundles/chinese/` and published with the static site. Upstream sources: [CTeX](https://github.com/CTeX-org/ctex-kit), [LuaTeX-ja](https://github.com/luatexja/luatexja), [Chinese JFM](https://ctan.org/pkg/chinese-jfm), [zhnumber](https://ctan.org/pkg/zhnumber), [lua-uni-algos](https://ctan.org/pkg/lua-uni-algos), [Fandol](https://ctan.org/pkg/fandol).
- **Nanum Myeongjo Regular**, SIL Open Font License 1.1, Korean TrueType font. Setup verifies the unmodified font and licence against SHA-256 pins, from [Google Fonts commit bd8f81ddb5c74d5c8897b36ad88b440266245103](https://github.com/google/fonts/tree/bd8f81ddb5c74d5c8897b36ad88b440266245103/ofl/nanummyeongjo). The font and its `OFL.txt` are published under `vendor/engine/bundles/chinese/`.
- **enumitem 3.11**, MIT; **fancyhdr 5.2**, LPPL 1.3-or-later; **IPAex Mincho 004.01**, IPA Font License Agreement v1.0. These list/header packages and the uncommon Han fallback font come from the same immutable TeX Live 2025 final archive, with SHA-256 pins in `scripts/setup.mjs`. Unmodified package/font files, licence/readme files and TeX Live metadata are published under `vendor/engine/bundles/chinese/`. Upstream sources: [enumitem](https://ctan.org/pkg/enumitem), [fancyhdr](https://ctan.org/pkg/fancyhdr), [IPAex fonts](https://ctan.org/pkg/ipaex).
- **opentype.js 1.3.4**, MIT. https://github.com/opentypejs/opentype.js . Licence under `vendor/opentype-LICENSE`.
- **PDF.js 4.10.38**, Apache-2.0. https://github.com/mozilla/pdf.js . Licence installed under `vendor/pdfjs/LICENSE`.
- **pdf-lib 1.17.1**, MIT. https://github.com/Hopding/pdf-lib . Used to retain only the PDF pages containing cached pictures. Licence installed as `vendor/pdf-lib-LICENSE.md`.
- **Rex BibTeX8 / MakeIndex WASM**, TeX Live 2026.0, built with Emscripten 4.0.23. Only BibTeX8, MakeIndex 2.18 and kpathsea are linked; applet algorithms are unchanged. Versioned corresponding source: https://github.com/TeX-Live/texlive-source/tree/tags/texlive-2026.0 ; dispatcher: https://github.com/TeXlyre/texlyre-busytex-build/tree/46ebb6216a5c1fe63dd1dc885831d1a8cef2dc86 . The dispatcher integration is AGPL-3.0, original BusyTeX is MIT, and the TeX Live tools retain their respective source-header licences. The verified runtime, dispatcher, notices and SHA-256 inventory are included under `runtime/busytex/`; `npm run build:tools` rebuilds it using `scripts/build-busytex.sh`. Setup and build verify the inventory before installing `vendor/bibliography/busytex.mjs` and `busytex.wasm`, with `BusyTeX-LICENSE` and `BusyTeX-NOTICE`. The adapter adds an ES module export and a conditional Node loader.

- **Biber 2.22 / Perl 5.38.2 WASM**, from the same pinned TeXlyre build. Biber itself uses Artistic License 2.0; Perl, its XS modules and native dependencies retain their respective licenses, in addition to the build integration license above. Source/build instructions: https://github.com/TeXlyre/texlyre-busytex-build/tree/46ebb6216a5c1fe63dd1dc885831d1a8cef2dc86/biber . The Perl dependency tree is distributed in `biber.data` and loaded only for Biber jobs.
- **BibLaTeX 3.22** and **logreq 1.0**, LPPL 1.3c. Pinned BibLaTeX source: https://github.com/plk/biblatex/tree/v3.22 ; logreq: https://ctan.org/pkg/logreq . Setup verifies both archives, substitutes BibLaTeX's release-version placeholders and preserves source headers and README licenses. Standard BibTeX `.bst` files come from https://ctan.org/pkg/bibtex and retain their source-header terms.
- **CodeMirror 6**, MIT, including its LaTeX stream mode, Lezer, DOM helpers and keyboard utilities. https://codemirror.net/ . Exact dependency versions are pinned in `package-lock.json`; `scripts/editor-vendor.mjs` bundles the editor for local and offline use and preserves component versions and licences in `vendor/codemirror-LICENSE.txt`.
- **esbuild 0.28.2**, MIT; used at build time to bundle CodeMirror and the local-file application, workers and tool factories. https://github.com/evanw/esbuild .
- **Binaryen 132.0.0**, Apache-2.0; used at build time only to apply Asyncify to the local-file LuaTeX engine. https://github.com/WebAssembly/binaryen . `scripts/async-wasm.mjs` reproduces the transform from the pinned LuaTeX module; the transformed module retains LuaTeX's GPL-2.0-or-later licence.
- **FontTools 4.60.1**, MIT; used at build time only. https://github.com/fonttools/fonttools .

Rex application code is under the root MIT license. Distributors must preserve the separate licenses of these components and make GPL/AGPL-covered corresponding source available as required by the relevant license; the upstream versioned source and build links above identify this build's provenance.

`vendor/` is generated by setup and is not committed. The static build copies it to `dist/vendor/`, preserves all installed component notices, and includes this document and the root MIT license. Rex source is copied to `dist/assets/`. The local release folder ships the same application and complete runtime resources bundled under `standalone/`, retains component licence/readme/notice files at their original `vendor/` paths, and includes this document and the root MIT license. Setup and build omit unused alternate format dumps and a build-only TikZ snapshot; TikZ's runtime packages are retained. Biber's generated data package omits only C/XS/object build files and File::ShareDir test fixtures, keeping the remaining upstream encoded blocks unchanged. Its loader metadata and package hash are updated accordingly; WASM algorithms, runtime modules, Unicode and locale data are unchanged. LuaTeX-ja's documentation source is omitted; its BSD notice and runtime source files are retained.
